# vidscribe — что осталось

Последняя сборка: `.autopilot/2026-11-23-vidscribe-cross-platform/` — vidscribe работает на Windows и Mac, с движками mlx, scribe (ElevenLabs) и whisper.

## Договорились — не пересматривать

- «а если Scribe использовать?» / «давай его поставим» — Scribe есть на обеих ОС; на Windows он по умолчанию, если задан `ELEVENLABS_API_KEY` (R02)
- На Mac по умолчанию остаётся локальный MLX, облако только по явному выбору — ADR-0010 (R05)
- Ключ ElevenLabs пользователь задаёт сам; его никогда не просят в чате и не печатают (R08i)

## Не доделано

- Проверка на настоящем Mac: `install.sh` и движок MLX проверены только тестами (R05, R09i)
- Проверка Scribe на настоящем API: нет ключа (R02)
- Публикация этой версии (форк на GitHub, `npx skills add` для неё) — только по просьбе пользователя

## Известные баги

- Mac на Intel не ставится: `install.sh` требует Apple Silicon, хотя scribe работал бы и там
- Whisper на Mac ставится только вручную — `install.sh` его не предлагает
- Явный `-e`/`VIDSCRIBE_ENGINE` не проверяется на доступность заранее (ошибка понятная, но приходит позже)
- Любая ошибка на CUDA (не только сбой CUDA) печатает `CUDA unavailable` и повторяет на CPU
