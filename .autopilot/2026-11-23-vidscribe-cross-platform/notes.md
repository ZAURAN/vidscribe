# Notes — existing code (read inline by the orchestrator; the repo is one script)

- `bin/vidscribe` (bash, ~200 lines) — the whole tool. Flow: prune `/tmp/vidscribe/{transcripts,videos,frames}` entries older than 3 days → parse args (`-o -l -f -c -m -a -h`; `-v --at --scan` print the "was removed" line and exit 1) → `WANT_VIDEO` = not `-a` and fmt in txt|srt → URL: `yt-dlp -q --no-warnings --no-playlist --no-simulate --no-mtime --print after_move:filepath -f <formats> --merge-output-format mp4 -o $TMP/%(id)s.%(ext)s` (video formats `bv*[height<=720]+ba/b[height<=720]/b/bv[height<=720]/bv/ba`, audio `ba/b`), first output line only; local: must be a file → ffprobe `a:u` (audio) and `V:u` (real video, excludes cover art) → no audio and no video: `vidscribe: no usable audio or video stream`; no audio and not keeping video: `vidscribe: no audio track to transcribe`, exit 1; no audio and keeping video: `vidscribe: no audio track; writing an empty transcript` + empty srt → otherwise ffmpeg to 16 kHz mono wav, DUR from the wav, run mlx-audio with an inline Python patch (the heredoc between `<<'PY'` and `PY`) using the interpreter from the shebang of `mlx_audio.stt.generate`, args `--model M --audio WAV --output-path $OUT --format $RUNFMT --max-tokens (8192+32*DUR, integer) --max-parallel-segments (32 if RAM >= 16 GiB else 8) [--language L] [--context C]`, its stdout to stderr → when keeping video: txt from srt (one cue per line), downloaded video moved to `/tmp/vidscribe/videos/<basename>`, a local video printed as an absolute path, `video: <path>` to stderr → ends-early check: if an srt exists and audio existed, last cue end vs DUR, gap > 30 s → `WARNING: last cue Xs < duration Ys; transcript ends early` → `transcript: $OUT.$FMT` to stderr → txt printed to stdout.
- RUNFMT = srt when keeping video, else the requested fmt. With `-f txt` and a video, both srt and txt are written.
- Env: `VIDSCRIBE_MODEL` (default `mlx-community/Qwen3-ASR-1.7B-8bit`), `VIDSCRIBE_OUTDIR` (default `/tmp/vidscribe/transcripts`).
- The inline patch prints `warning: transcript cut off in HH:MM:SS-HH:MM:SS (likely a repetition loop)` and `warning: mlx-audio changed, per-piece token cap off (...)`.
- `install.sh` — macOS arm64 + Homebrew only: `brew install uv ffmpeg yt-dlp`, `uv tool install --force mlx-audio --prerelease=allow`, symlink `bin/vidscribe` into `~/.local/bin`.
- `tests/silent-video.sh` — silent 10 s video → empty txt+srt, `video: <abs path>` for absolute and relative input.
- `skill/SKILL.md` — the agent skill (3 steps + reference). `docs/usage.md`, `README.md`, `docs/decisions/0001…0009` + their README table. ADR-0001 = local-only, no cloud.
